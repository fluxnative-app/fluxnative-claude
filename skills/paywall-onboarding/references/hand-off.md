# Hand-off

Where work goes when it passes these screens' rules. Other skills are used only if installed; the fallback applies when one is not.

- Visual polish of these screens → if `mobile-deslop` is installed, use it. Fallback: one filled primary button per viewport, one accent, no gradient behind text, sentence-case labels.
- Paywall and onboarding copy, sample prices in screenshots → if `app-sample-content` is installed, use it. Fallback: product words, not slogans; the headline says what the person gets.
- Purchase SDK setup, store products and entitlements → the payment provider's docs.
